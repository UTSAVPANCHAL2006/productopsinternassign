01 · Patterns (read this first)

What the 100 apps say

Assignment ask: don’t dump rows — cluster and say where easy wins are vs outreach.

  1. Auth: OAuth2 (56), API key (53), Bearer token (27). Default toolkit adapters should cover OAuth2 + API key.
  2. Access: 74/100 self-serve · 23/100 paid/admin/partner-gated — that gated set is the ops outreach queue.
  3. Buildability: 92/100 can be toolkit work now (ready / caveats). 7 need outreach first.
  4. MCP: first pass over-counted marketplaces as MCP (44). After cleanup: 23 credible Model Context Protocol signals.
  5. Common blocker: OAuth Connected App + sandbox setup friction; many customers require admin install approval.

03 · The agent (not by hand)

Pipeline that researched the 100

Python agent: fetch public docs → structure with OpenAI → optional Composio toolkit catalog check → verify → correct.

1 SeedLoad 100 apps from data/apps.json
2 FetchHTTP pull developer docs into evidence packs
3 StructureLLM fills auth / access / API / MCP / verdict JSON
